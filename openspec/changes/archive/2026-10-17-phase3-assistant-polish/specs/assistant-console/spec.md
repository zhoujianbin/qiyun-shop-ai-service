# Spec Delta

## Purpose

定义客服工作台与客户对话界面的行为：会话列表、对话窗口的流式渲染、引用展示与转人工处理；本补丁补充回答反馈入口。

## ADDED Requirements

### Requirement: 回答反馈

客户与客服 SHALL 对每条已完成回答给出正负反馈；负反馈 MUST 可选择原因，反馈 MUST 持久化到该消息的元数据中，且同一消息的反馈以最后一次为准。

#### Scenario: 点赞与点踩

- **WHEN** 客户点击某条回答的赞或踩
- **THEN** 该消息的反馈被记录，界面显示当前选择状态

#### Scenario: 点踩需选原因

- **WHEN** 客户点踩
- **THEN** 出现原因选项（答非所问 / 缺少引用 / 内容过时 / 不安全），选择后一并保存

#### Scenario: 重复反馈覆盖

- **WHEN** 客户对同一消息先点赞再点踩
- **THEN** 只保留最后一次反馈
