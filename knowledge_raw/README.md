# 栖云智家企业知识库

本知识库覆盖产品、交易履约、安装、售后、账户设备、云服务、客服运营及安全治理。

## 使用原则
1. 真源优先级与冲突处理见内部治理文档（`SOURCE_OF_TRUTH.md`，不随仓库分发）。
2. 产品参数查 `01_产品知识/*/产品主档.md`；时限、状态和权限查 `13_结构化规则/`。
3. 订单、物流、预约、绑定、订阅和工单的当前状态必须查询业务系统，静态文档不能代替实时结果。
4. 回答应注明 document_id；资格判断同时注明 rule_id。
