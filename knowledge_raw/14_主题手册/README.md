# 主题手册导航

主题手册是给人和 Agent 深读的第二层知识。原有 00-13 目录保留为检索卡片、结构化真源和场景入口；本目录负责把相关卡片串成完整业务上下文。

## 分层规则

- 第一层：本导航，说明主题和阅读路径。
- 第二层：产品手册、流程手册、SOP 手册，提供连续上下文。
- 第三层：原有业务卡片、产品主档和 YAML，作为精确引用与执行真源。
- 第四层：场景案例，用于验证规则组合，不反向定义政策。

## RAG 使用建议

不要把整篇主题手册直接作为单一向量块。导入时按二级标题切分，保留 document_id、产品 ID、rule_id、主题路径和标题层级；原有短文档可作为高精度召回入口，主题手册用于扩展上下文和回答复杂问题。
