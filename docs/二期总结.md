# 二期（企业知识库平台）总结

> 一页纸：做了什么 / 没做什么 / 已知限制 / 下一步。
> 变更集：`openspec/changes/phase2-knowledge-platform`（74 条任务）。

## 1 做了什么

| 层面 | 交付 |
|---|---|
| 数据 | 一期 3 张预留表补 9 列（`embedding_status` / `identity_level` / `change_summary` 等）、`chunk.embedding` 1024→**512** 并重建 HNSW；新增 7 张表；库内表数 48→**55**；12 个 `knowledge:*` 权限码 + 4 个角色；`AUDITOR` 收窄 |
| 迁移 | `db/migrations/0001–0006` + `scripts/apply_migrations.py`（按 checksum 判重、单文件事务、失败即停）；`schema.sql` / `docs/schema.sql` / `generated.py` 三者一致 |
| 导入 | MD/TXT/DOCX + 规则 YAML 专用通道；sha256 去重、`Idempotency-Key` 复用、单文件失败隔离、错误清单（文件名+原因+行号） |
| 切片与向量 | 按标题层级切（≤600 字、保留 `title_path` 与原文行号）；本地 `bge-small-zh-v1.5` 512 维归一化、查询侧加指令前缀；worker 支持 `--once`；`reindex_embeddings.py` 可断点续跑 |
| 规则 | 24 条 YAML 规则入库（政策 9 / 保修 7 / 升级 8）；六键条件契约；冲突检测 BLOCK/WARN；冲突解决解锁发布 |
| 发布 | 状态机、六道门禁、单一 ACTIVE、定时生效、回滚（复制切片）、审计与 outbox 事件 |
| 审核 | 队列、认领互斥、锚定批注、决定留痕、自审可配置并标记 |
| 检索 | 全文 + 向量双路、RRF(60) 融合、阈值 0.35、`hits`（稳定引用）/ `debug`（分数）分段、检索日志；`search()` 进程内可直接调用 |
| 治理 | 五类报告（重复/过期/孤立/冲突/与商品不一致）+ 概览；下钻带过滤条件 |
| 前端 | 7 个页面（概览/文档/详情/编辑/审核/检索测试/治理）+ 发布弹窗；`react-markdown` 只读预览；首屏 gzip **236 KB**（预算 260 KB）；知识库代码独立分包 |
| 契约 | `openapi.json`/`openapi.yaml` 重新导出：113 路径 / 139 操作；`check_frontend_contract.py` problems=0 |

## 2 没做什么（属三/四期，本期只预埋）

- 对话、会话、消息、流式回答、意图识别、转人工、身份核验 → 三期
- RAG 生成、编排框架、重排、多轮改写 → 三期
- 本体、工具调用（查订单/查商品）、工作流编排、评测集与回归门禁 → 四期
- 规则**运行时求值**（本期只存储 + 冲突治理）→ 三期策略层

**预埋点**（均已落地并验收）：检索服务化、引用结构化、规则六键语义化、outbox 事件（`knowledge.*`）、权限码三段式、`identity_level` 过滤、`assistant` schema 规划（只写文档不建表）。

## 3 已知限制

| # | 限制 | 影响 | 缓解 |
|---|---|---|---|
| 1 | 一期前端 `ROLE_CODES`（6 个）与后端角色码（7 个）**零重叠** | 前端按角色分支不可用；本期只追加 4 个新角色码，未修既有 6 个 | 靠 `permissions` 数组鉴权；后续单独修 |
| 2 | 编辑器页**只能预览切片，不能保存** | 缺 `POST /documents/{id}/versions` 接口，改稿仍需走导入 | 下一步补接口 |
| 3 | DOCX 无真实素材 | 解析器只由 fixture 验证 | 三期前补真实 DOCX 回归 |
| 4 | 检索参数（RRF k=60、阈值 0.35）基于约 500 条切片调参 | 语料增长后可能需重调 | 三期接入前做一次 10 万条压测 |
| 5 | "孤立文档"口径偏严（129/158） | 治理看板噪音大 | 可改为"导航页入链也算引用" |
| 6 | 治理报告实时计算，无历史快照 | 无法看趋势 | 需要时加周报任务 |
| 7 | 批注回复 UI 未做（`parent_id` 已留字段） | 只能单条批注 | 后续迭代 |
| 8 | 迁移只做加法，回滚需人工执行反向语句 | 升级事故恢复靠文档 | 见 `docs/知识库运维.md` §1.5 |
| 9 | 自审默认开启（`KNOWLEDGE_ALLOW_SELF_REVIEW=true`） | 单人开发便利，企业上线需评估 | 关闭即返回 409 |

## 4 下一步

1. **补 `POST /documents/{id}/versions`**，让编辑器可保存（当前唯一的功能缺口）。
2. **三期启动**：新建 `assistant` schema（conversation/message/handoff/identity_verification/retrieval_trace），`ai:*` 权限码，直接调 `knowledge_retrieval.search()`。
3. **语料扩充**：PDF/XLSX 导入、真实 DOCX 回归、10 万条压测。
4. **规则第 25 条**：`consumables` 块是否纳管（design Open Question 2）。
5. **一期遗留**：前端角色码对齐（需改一期既有行，单独授权）。
