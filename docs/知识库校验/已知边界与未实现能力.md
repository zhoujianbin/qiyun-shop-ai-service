# 已知边界与未实现能力

本知识库定义业务语义和处理规范，不提供真实库存、价格、订单、物流、安装资源、设备在线状态、录像、订阅、维修和工单事实。它不构成远程开锁、查看摄像头、支付退款、物流拦截或设备控制能力。法律、渠道和地区规则变化后需由业务与法务复核发布；未配置工具时 Agent 只能解释流程或转人工。
