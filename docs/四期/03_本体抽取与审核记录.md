# 四期本体抽取与审核记录

> 目的：四期本体里的 `SYMPTOM_OF`、`REMEDY` 两类关系**没有现成数据源**，由文档关键词抽取生成候选（全部 `DRAFT`），再经一次 AI 审核后落库。
> 本文件是这次审核的留痕——**没有人工审核**，业务侧如需收紧，直接改 `app/services/ontology_review.py` 的两张表并重跑 `scripts/ontology_seed.py`。

## 1 抽取规则（可复现）

| 项 | 规则 |
|---|---|
| 故障现象来源 | `knowledge_raw/01_产品知识/*/故障诊断.md` 的二级标题（10 条） |
| 故障现象编码 | `SYM-<产品码>-<序号>`，序号按文件内标题顺序，稳定可重放 |
| 别名 | 标题原文直接作为别名，便于口语命中 |
| `SYMPTOM_OF` | 标题+正文按关键词表匹配部件，命中第一个即止（顺序：锁芯 → 电池 → 灯体驱动 → 基站 → 锁体电子 → 主机） |
| `REMEDY` | 同一段正文可能命中多个处置动作，全部收下 |
| escalation 触发词 | 只映射语义明确的 8 个（`battery_swelling`/`battery_fire` → 电池 等） |
| 抽不出来 | 跳过并记录原因，**不猜** |
