## G 流式与降级

| # | 判据 | 验证方式 |
|---|---|---|
| G1 | 事件顺序 | `meta → (ping)* → (tool)* → (delta)* → (action\|citations) → done`；老三期 6 事件载荷字段集合不变 |
| G2 | tool_calls 不出流 | 抓全流断言：无 `tool_calls`/`arguments`/`call_` 字样出现在任何事件载荷 |
| G3 | 缓冲不早于 tool 事件 | 带 tools 轮次：`tool` 事件的 index < 缓冲叙述首个 `delta` 的 index |
| G4 | length 判失败 | 注入 `finish_reason=length` → 消息 `status=FAILED`（不是 DONE 的空回答） |
| G5 | 业务拒绝透传 | `ORDER_STATE_INVALID` → 回答含原 code 语义与出路（"走退货退款流程"），不含自造数字 |
| G6 | 404 统一 | 他人订单 / 不存在订单 → 同一句"没有找到该订单" |
| G7 | 禁止串零命中 | 事实类回答跑 `forbidden_patterns`（金额 `\d+\.\d{2}元`、手机、他人单号）→ 0 命中 |
