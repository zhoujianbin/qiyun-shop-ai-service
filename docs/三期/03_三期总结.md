# 三期（智能客服）总结

> 变更集：openspec/changes/phase3-assistant（42 条任务）。本文为交付时的现状快照。

## 1 做了什么

| 层 | 交付 |
|---|---|
| 数据 | 新 schema assistant 6 表（conversation/message/citation/handoff/identity_verification/retrieval_trace）；表数 55 → 61；迁移 0007 + 0008 |
| 权限 | 5 个 ai:* 三段码；AI_AGENT / AI_SUPERVISOR 角色；CS_SUPERVISOR 加 ai:handoff:read |
| LLM | app/integrations/llm.py：OpenAI 兼容（DeepSeek deepseek-flash）+ fake；只转发 content，丢弃 reasoning_content；测试环境强制 fake |
| 编排 | assistant_graph.py：plan → execute ⇄ replan → finalize；计划 ≤2 步、≤4 步、1 次改写、30s；ToolSpec 三标记 |
| 会话 | 行锁分配 seq、client_msg_id 幂等、上下文窗口、限流、可见性、关闭 |
| 流式 | POST /ai/conversations/{id}/messages:stream：meta → ping(15s) → delta → citations → done/error；占位消息 + 僵尸清理 |
| 引用 | 服务端从 hits 生成 citation，带 entity_tags（product_line / rule_id） |
| 拒答与护栏 | 无命中不调模型（先澄清再拒答）；实时事实只给口径；escalation triggers + 中文别名表命中即给安全提示 |
| 核验 | 订单号 + 收货手机后四位；30 分钟；6 字段快照白名单；失败话术不可枚举；3 次锁定 |
| 转人工 | 认领制；接单置 ai_paused（AI 停止自动回答）；关单必填结论；back_to_ai 恢复 |
| 前端 | 客户对话页 /assistant、客服工作台 /admin/assistant；SSE 用 fetch 流读取；首屏 gzip 236 KB |
| 文档 | docs/三期对话协议.md（事件/状态/断线/非流式接口） |

## 2 没做什么（属四期）

- 通用工具注册表与写操作工具调用（查订单/查商品/改地址）
- 本体与实体链接（只在 citation.entity_tags 留两类实体）
- 评测集、回归门禁、A/B
- 多步任务编排（门锁故障→上门→备件）
- 语音/图片消息、多客服排队与 SLA 工单

## 3 已知限制

| # | 限制 | 影响 | 缓解 |
|---|---|---|---|
| 1 | escalation 的中文别名表按 YAML 语义补，非业务方词表 | 护栏覆盖可能偏离真实话术 | 需业务确认后替换 ESCALATION_ALIASES |
| 2 | 固定事实快照走 POST /identity 返回，不进入对话回答 | 对话里看不到订单卡片 | 若要「聊天里出现订单卡」，需扩 spec（回答带引用 vs 快照无引用的冲突） |
| 3 | 自动转人工只挂了 USER_REQUEST / IDENTITY_FAILED | HIGH_RISK_RULE / NO_HIT / MODEL_ERROR 需在流式链路补挂 | 接口已留，约 0.5 人日 |
| 4 | 点赞点踩后端已通（POST /ai/messages/{id}/feedback），前端图标未接 | 验收 I7 部分达成 | 前端两个 onClick，约 0.2 人日 |
| 5 | 不补发断线内容（无 Last-Event-ID） | 弱网时半截回答丢失 | 重连拉历史；僵尸消息置 FAILED |
| 6 | 会话保留期 90 天，清理靠脚本手动跑 | 无定时调度 | 可挂 cron |
| 7 | 成本未做预算控制 | 无上限保护 | 有逐条 token 埋点，可按总量对账 |

## 4 下一步

1. 业务确认 escalation 中文别名表；补挂剩余 3 类自动转人工。
2. 前端接点赞点踩；补「订单快照卡片进对话」的产品决策。
3. 四期：ToolSpec 注册 order_query / shipment_query（只读）→ 写操作工具（鉴权+幂等+审计）；本体用 citation.entity_tags 起步；评测直接用 message.metadata.feedback + retrieval_trace。
