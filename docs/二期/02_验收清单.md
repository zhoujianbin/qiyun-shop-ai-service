# 二期验收清单

用法：每条给出「通过/不通过 + 证据（命令与输出）」。不通过不要解释成设计如此，要么修，要么列入待办并写明影响。

## A 通用门禁（每次提交前）

| # | 验收项 | 验证方式 | 证据 |
|---|---|---|---|
| A1 | 后端全量测试通过 | `python -m pytest -q` | 输出 `N passed`，N ≥ 53 |
| A2 | 前端调用与后端契约一致 | `python scripts/check_frontend_contract.py` | `problems=0` |
| A3 | 前端类型与构建 | `cd web && npx tsc --noEmit && npm run build` | 0 error、构建成功、无循环 chunk 警告 |
| A4 | 首屏预算 | 构建后看 `dist/index.html` 引用文件 gzip 合计 | < 260KB |
| A5 | 迁移可重放 | 在空库上 `create_db.py` + `apply_migrations.py` | 表数量与 `schema.sql` 一致，无报错 |
| A6 | 无敏感信息 | `git diff` 检查 + `grep -rE 'password|secret|127\.0\.0\.1' app/ web/src/` | 无口令/连接串/绝对路径 |

## D 元数据、版本与发布

| # | 验收项 | 验证方式 |
